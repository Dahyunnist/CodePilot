# S5：集中管理工具说明

## 1. 本阶段目标

Agent 原先直接读取 `ToolRegistry.specs`，工具结果说明又在 Agent 中维护一份名称到中文标签的映射。新增工具时，schema 与标签需要分别修改，容易出现信息不一致。

## 2. 实现

`ToolRegistry.read_tools()` 是工具元数据的单一读取入口，返回工具名称、用途描述和参数 JSON Schema。`Agent` 每次请求模型时通过该方法获取可用工具；模型收到的仍是标准 function tool schema，包含必填参数与字段说明。

工具执行结果的说明直接复用同一份工具描述。删除 Agent 内的工具标签映射，避免新增工具时遗漏展示名称。

## 3. 边界

这不是供模型调用的额外工具。`read_tools()` 是 Agent 与工具注册表之间的程序接口；模型仍通过 API 的 `tools` 字段看到可用工具，并通过 function call 请求执行。

当前注册表在初始化时构建工具集合。`read_tools()` 集中读取既有集合，不提供运行时插件注册或动态权限变更。
