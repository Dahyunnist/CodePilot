# CP-3/CP-4 净发布候选摘要（2026-11-16）

## 候选边界

本分支是已发布项目历史上的快进候选，不是新的 orphan root。当前树按 allowlist 保留 `codepilot/` 运行源码、项目依赖与 Docker 配置、README、安全/架构说明、CP-3/CP-4 离线测试、Skill 确定性 fixture，以及发布历史扫描器。删除文件仍可能存在于祖先提交中；本分支没有清理或改写历史对象。

以上边界只描述当前树，不能视作历史脱敏保证。本轮不读取、不运行或导出隐藏题、gold、账单 CSV、密钥或私人数据；也不改写已发布分支。

## CP-3：安全与可观测性

- Trace 事件固定携带 logger 的 `run_id`、`trace_id`、事件时间和事件步数；调用者额外字段不能覆盖这些标识。
- 模型、工具、补丁与审批事件按父 span 关联。Trace 省略源码、补丁正文、命令输出和密钥值。
- OpenTelemetry span 只接受明确允许的运行元数据；任务说明、指令和测试命令不写入 JSONL，也不导出到 span 属性。
- 路径策略拒绝仓库外路径和敏感文件；工具调用参数由 schema 校验。
- Trace 身份负例回归验证伪造元数据不能改写真实 run/trace 身份。
- 生产 OTLP Collector 接入与独立安全审计仍未完成。

## CP-4：Skill 约束

- Skill 定义输入契约、允许工具、预算和退出条件。
- Skill 工具白名单在模型可见工具和 Agent 执行层分别校验。
- 离线消融只用固定的普通 fixture 投影约束；`model_calls=0`，不代表模型效果比较。
- 因而 CP-4 的离线约束/回归范围可验收；真实仓库修复效果和 Skill 收益未由此验收。
