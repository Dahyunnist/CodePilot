# CP-3/CP-4 净发布候选摘要（2026-11-16）

## 候选边界

本分支从新的 orphan root 创建，不继承既有公开分支历史。文件按 allowlist 纳入：`codepilot/` 运行源码、项目依赖与 Docker 测试配置、README、安全/架构说明、CP-3/CP-4 所需离线测试、Skill 确定性 fixture，以及发布历史安全扫描器。

未纳入隐藏或 holdout 测试、报告与 CSV、账单材料、CP-2 评测数据、临时文件、运行日志、模型输出或本机 `.env`。本摘要只引用仓库相对路径，不记录本机路径。

## CP-3：安全与可观测性

- Trace 事件固定携带 logger 的 `run_id`、`trace_id`、事件时间和事件步数；调用者额外字段不能覆盖这些标识。
- 模型、工具、补丁与审批事件按父 span 关联。Trace 省略源码、补丁正文、命令输出和密钥值。
- 路径策略拒绝仓库外路径和敏感文件；工具调用参数由 schema 校验。
- Trace 身份负例回归验证伪造元数据不能改写真实 run/trace 身份。

## CP-4：Skill 约束

- Skill 定义输入契约、允许工具、预算和退出条件。
- Skill 工具白名单在模型可见工具和 Agent 执行层分别校验。
- 离线消融只用固定的普通 fixture 投影约束；`model_calls=0`，不代表模型效果比较。

定向离线回归：87 项通过，覆盖配置、模型协议、提示、工具注册、运行图、状态迁移、安全、Skill 与 Trace。完整离线回归以本机正常权限运行：201 项通过、2 项因 Windows junction 权限跳过。Docker daemon 可连接，`codepilot-runner:0.1` 镜像已存在；此轮没有运行 Docker baseline、模型请求或真实外部遥测调用。
