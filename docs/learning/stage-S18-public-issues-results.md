## 分析

每项模型都花了 10–11 步读取源码和搜索，却没有尝试补丁或测试。模型累计输入 Token 高于输出很多，因为多轮对话会反复携带工具和历史上下文。预算保护阻止了无测试验证的改动，但本轮不能证明修复能力。

下一批不得复用这三项公开任务。新任务应在冻结前按轨迹估算设更高的单项预算，并减少每轮重复携带的无关历史。可先用一项全新任务验证预算规划，再扩展批次；费用继续服从累计 $4 上限。公开 issue 仍可能与训练数据重叠，结论只适用于这些小样本。
